# Billing Engine Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give AKPA directors a working tuition ledger — automatic recurring charges, per-family invoices, manual payment recording, and a revenue dashboard — inside the existing staff portal.

**Architecture:** Three new Postgres tables (`charges`, `invoices`, `payments`) extend the existing `children`/`guardians` model. Recurring tuition is generated by a SQL function run daily by `pg_cron`, with all period/proration math in SQL so the cron job and the manual "Generate now" button share one code path. New Next.js routes under `/billing` follow the app's existing Server Component + Server Action conventions. A restricted view gives staff a balance signal without exposing dollar figures.

**Tech Stack:** Next.js 16.2 (App Router, Server Components, Server Actions), React 19.2, Supabase (Postgres + RLS + `@supabase/ssr`), `pg_cron`, TypeScript, Tailwind (hand-rolled utility classes), Vitest (newly introduced — see Global Constraints).

**Spec:** `docs/superpowers/specs/2026-08-14-billing-engine-design.md`

## Global Constraints

- **Migrations:** one file, `supabase/migrations/20260814120000_billing_engine.sql`. Naming convention `YYYYMMDDHHMMSS_description.sql`. Must be timestamped `>= 20260814`.
- **RLS on every new table:** `to authenticated`, `using (tenant_id = public.current_tenant_id() and public.current_role() in ('director', 'platform_admin'))`, with matching `with check (...)` on writes. Policy naming: `"<table>_select"`, `"<table>_write"`.
- **Helper functions already exist** (defined in `20260802152626_fix_rls_recursive_helper_functions.sql`): `public.current_tenant_id()` returns uuid, `public.current_role()` returns `public.app_role`. Do not redefine them.
- **`set_updated_at()` trigger function already exists** (from `20260802141847_init_roles_and_profiles.sql`). Attach to any table with an `updated_at` column: `create trigger set_<table>_updated_at before update on public.<table> for each row execute function public.set_updated_at();`
- **`src/types/database.types.ts` is hand-authored, NOT generated.** Every new table, enum, function, and view must be added by hand. Convention: snake_case Postgres name ↔ PascalCase TS alias, exported as `export type X = "a" | "b";` near the top, then registered in the `Enums:` map at the bottom. `Update` types are always `Partial<Database["public"]["Tables"]["<t>"]["Insert"]>`.
- **`Views: Record<string, never>;`** at line ~1134 must be replaced with a real view entry for `child_balance_status` (Task 4).
- **Supabase server client:** `import { createClient } from "@/lib/supabase/server";` then `const supabase = await createClient();` — it is async, always await it.
- **Role gating is inline, first line of the Server Component:** `const session = await requireRole(["director", "platform_admin"]);` from `@/lib/auth/dal`. There is no middleware role check.
- **No UI component library.** `src/components/ui/` contains only `stat-tile.tsx`. Do not add shadcn/ui, Radix, clsx, or cva. Hand-write Tailwind classes matching existing patterns:
  - Card/panel: `overflow-hidden rounded-xl border border-gray-200 bg-white`
  - Panel header: `border-b border-gray-100 px-4.5 py-3.5` containing `font-serif text-[14.5px] font-semibold text-gray-900`
  - Table header row: `border-b border-gray-100 bg-gray-50 px-4.5 py-2.5 text-[10px] font-bold tracking-[.13em] text-gray-400 uppercase`
  - Table data row: `border-b border-gray-100 px-4.5 py-3 hover:bg-gray-50`, cells `text-[13px] text-gray-600`, money cells add `tabular-nums`
  - Badge: `rounded-full px-2.5 py-1 text-[10.5px] font-bold tracking-[.07em] uppercase` + tone classes (`bg-green-50 text-green-700`, `bg-amber-50 text-amber-700`, `bg-red-50 text-red-700`, `bg-gray-100 text-gray-600`)
  - Input: `rounded-md border border-gray-300 px-3 py-2 text-sm focus:border-[var(--brand-accent)] focus:outline-none`
  - Primary button: `rounded-md bg-[var(--brand-accent)] px-4 py-2 text-sm font-semibold text-[#06323A] hover:opacity-90`
  - Secondary button: `rounded-md border border-gray-300 px-4 py-2 text-sm font-medium text-gray-700 hover:bg-gray-50`
  - Empty state: `px-4.5 py-6 text-center text-sm text-gray-500`
- **Money is `numeric(10,2)` in Postgres, `number` in TS.** Always render with `.toFixed(2)` and a `$` prefix; `null` renders as `—`.
- **Server actions:** `"use server";` is the first line of the file (applies to all exports). Actions re-verify their own session — a server action is a public endpoint regardless of what the calling page checked. Use `requireRole(["director", "platform_admin"])` for all billing actions.
- **RLS-blocked writes return zero rows, not an error.** For actions needing user-facing failure messages, chain `.select("id").maybeSingle()` after the write and distinguish `error` (real failure) from `!data` (blocked by RLS) from success.
- **`revalidatePath`** after every mutation, on every affected route.
- **Existing dependencies only** — no new npm packages except the Vitest devDependencies in Task 1. `zod` is in `package.json` but unused in existing action files; match the existing manual-validation style rather than introducing zod here.
- **Existing biweekly label is authoritative:** `CADENCE_LABELS.biweekly = "Bi-weekly (1st & 3rd Mondays)"` in `src/lib/children/labels.ts`. Biweekly periods are the month's 1st and 3rd Monday for every biweekly child.

- [ ] **Step 5: Implement the period math**

Create `src/lib/billing/periods.ts`:

```ts
import type { BillingCadence } from "@/types/database.types";

const DAY_MS = 24 * 60 * 60 * 1000;

function iso(d: Date): string {
  return d.toISOString().slice(0, 10);
}

function utc(y: number, m0: number, day: number): Date {
  return new Date(Date.UTC(y, m0, day));
}

/** Monday = 1 in getUTCDay() terms (Sunday = 0). */
function isMonday(d: Date): boolean {
  return d.getUTCDay() === 1;
}

export function firstMondayOf(year: number, monthIndex0: number): Date {
  const first = utc(year, monthIndex0, 1);
  const shift = (8 - first.getUTCDay()) % 7;
  return utc(year, monthIndex0, 1 + shift);
}

export function thirdMondayOf(year: number, monthIndex0: number): Date {
  const first = firstMondayOf(year, monthIndex0);
  return new Date(first.getTime() + 14 * DAY_MS);
}

export function periodFor(
  cadence: BillingCadence,
  on: Date,
): { start: string; end: string } | null {
  const y = on.getUTCFullYear();
  const m = on.getUTCMonth();
  const day = on.getUTCDate();

  if (cadence === "monthly") {
    if (day !== 1) return null;
    return { start: iso(utc(y, m, 1)), end: iso(utc(y, m + 1, 0)) };
  }

  if (cadence === "weekly") {
    if (!isMonday(on)) return null;
    return { start: iso(on), end: iso(new Date(on.getTime() + 6 * DAY_MS)) };
  }

  // biweekly: the month's 1st and 3rd Mondays.
  if (!isMonday(on)) return null;
  const first = firstMondayOf(y, m);
  const third = thirdMondayOf(y, m);

  if (iso(on) === iso(first)) {
    return { start: iso(on), end: iso(new Date(third.getTime() - DAY_MS)) };
  }
  if (iso(on) === iso(third)) {
    const nextFirst = firstMondayOf(m === 11 ? y + 1 : y, (m + 1) % 12);
    return { start: iso(on), end: iso(new Date(nextFirst.getTime() - DAY_MS)) };
  }
  return null;
}

export function prorationFraction(
  periodStart: string,
  periodEnd: string,
  startDate: string,
): number {
  if (startDate <= periodStart) return 1;

  const start = new Date(`${periodStart}T00:00:00Z`).getTime();
  const end = new Date(`${periodEnd}T00:00:00Z`).getTime();
  const enrol = new Date(`${startDate}T00:00:00Z`).getTime();

  if (enrol > end) return 0;

  const totalDays = Math.round((end - start) / DAY_MS) + 1;
  const billedDays = Math.round((end - enrol) / DAY_MS) + 1;
  return Math.round((billedDays / totalDays) * 10000) / 10000;
}
```

```sql
-- Recomputes an invoice's total from its live charges and re-derives status
-- from what's been paid. Called after any charge or payment change.
create or replace function public.recalc_invoice_totals(p_invoice_id uuid)
returns void
language plpgsql
security definer
set search_path = public
as $$
declare
  v_total numeric(10, 2);
  v_paid numeric(10, 2);
  v_status public.invoice_status;
begin
  select coalesce(sum(parent_amount), 0) into v_total
  from public.charges
  where invoice_id = p_invoice_id and void = false;

  select coalesce(sum(amount), 0) into v_paid
  from public.payments
  where invoice_id = p_invoice_id;

  if (select status from public.invoices where id = p_invoice_id) = 'void' then
    return;
  end if;

  if v_paid <= 0 then
    v_status := 'open';
  elsif v_paid < v_total then
    v_status := 'partial';
  else
    v_status := 'paid';
  end if;

  update public.invoices
  set total_amount = v_total, amount_paid = v_paid, status = v_status
  where id = p_invoice_id;
end;
$$;
```

```sql
-- (creating the invoice if needed), and prorates the child's first period.
-- Idempotent: the charges_tuition_period_key index makes re-runs no-ops.
create or replace function public.generate_recurring_charges(
  p_tenant_id uuid,
  p_on date
)
returns integer
language plpgsql
security definer
set search_path = public
as $$
declare
  v_child record;
  v_period_start date;
  v_period_end date;
  v_first_monday date;
  v_third_monday date;
  v_next_first_monday date;
  v_fraction numeric;
  v_total_days integer;
  v_billed_days integer;
  v_subsidy numeric(10, 2);
  v_parent numeric(10, 2);
  v_period_rate numeric(10, 2);
  v_guardian_id uuid;
  v_invoice_id uuid;
  v_created integer := 0;
begin
  -- Period boundaries per cadence, mirroring src/lib/billing/periods.ts.
  v_first_monday := date_trunc('month', p_on)::date
    + ((8 - extract(dow from date_trunc('month', p_on))::integer) % 7);
  v_third_monday := v_first_monday + 14;
  v_next_first_monday := (date_trunc('month', p_on) + interval '1 month')::date
    + ((8 - extract(dow from (date_trunc('month', p_on) + interval '1 month'))::integer) % 7);

  for v_child in
    select c.id, c.location_id, c.weekly_rate, c.subsidy_weekly_amount,
           c.cadence, c.funding_type, c.start_date
    from public.children c
    where c.tenant_id = p_tenant_id
      and c.status = 'active'
      and c.weekly_rate is not null
  loop
    v_period_start := null;
    v_period_end := null;

    if v_child.cadence = 'monthly' then
      if extract(day from p_on) = 1 then
        v_period_start := p_on;
        v_period_end := (date_trunc('month', p_on) + interval '1 month' - interval '1 day')::date;
        v_period_rate := v_child.weekly_rate * 52 / 12;
      end if;

    elsif v_child.cadence = 'weekly' then
      if extract(dow from p_on) = 1 then
        v_period_start := p_on;
        v_period_end := p_on + 6;
        v_period_rate := v_child.weekly_rate;
      end if;

    elsif v_child.cadence = 'biweekly' then
      if p_on = v_first_monday then
        v_period_start := p_on;
        v_period_end := v_third_monday - 1;
        v_period_rate := v_child.weekly_rate * 2;
      elsif p_on = v_third_monday then
        v_period_start := p_on;
        v_period_end := v_next_first_monday - 1;
        v_period_rate := v_child.weekly_rate * 2;
      end if;
    end if;

    continue when v_period_start is null;

    -- Skip children who haven't started yet as of this period's end.
    continue when v_child.start_date is not null and v_child.start_date > v_period_end;

    -- Prorate the first period if enrollment lands mid-period.
    v_fraction := 1;
    if v_child.start_date is not null and v_child.start_date > v_period_start then
      v_total_days := (v_period_end - v_period_start) + 1;
      v_billed_days := (v_period_end - v_child.start_date) + 1;
      v_fraction := round(v_billed_days::numeric / v_total_days::numeric, 4);
    end if;

    -- Split subsidy vs parent copay. Private-pay children carry no subsidy.
    if v_child.funding_type = 'private' or v_child.subsidy_weekly_amount is null then
      v_subsidy := 0;
      v_parent := round(v_period_rate * v_fraction, 2);
    else
      v_subsidy := round(
        (v_child.subsidy_weekly_amount * (v_period_rate / v_child.weekly_rate)) * v_fraction, 2);
      v_parent := round(v_period_rate * v_fraction, 2) - v_subsidy;
    end if;

    -- The payer guardian groups the invoice. Skip children with no payer set.
    select cg.guardian_id into v_guardian_id
    from public.child_guardians cg
    where cg.child_id = v_child.id and cg.is_payer = true
    limit 1;

    continue when v_guardian_id is null;

    -- Reuse this guardian's invoice for the period, or open one.
    select i.id into v_invoice_id
    from public.invoices i
    where i.guardian_id = v_guardian_id
      and i.period_start = v_period_start
      and i.period_end = v_period_end
      and i.status <> 'void'
    limit 1;

    if v_invoice_id is null then
      insert into public.invoices (
        tenant_id, location_id, guardian_id, period_start, period_end, due_date
      )
      values (
        p_tenant_id, v_child.location_id, v_guardian_id, v_period_start, v_period_end,
        v_period_start + 7
      )
      returning id into v_invoice_id;
    end if;

    begin
      insert into public.charges (
        tenant_id, location_id, child_id, invoice_id, type,
        period_start, period_end, description, subsidy_amount, parent_amount
      )
      values (
        p_tenant_id, v_child.location_id, v_child.id, v_invoice_id, 'tuition',
        v_period_start, v_period_end,
        'Tuition ' || to_char(v_period_start, 'Mon DD') || ' – ' || to_char(v_period_end, 'Mon DD'),
        v_subsidy, v_parent
      );
      v_created := v_created + 1;
    exception when unique_violation then
      -- Already charged for this period; leave it alone.
      null;
    end;

    perform public.recalc_invoice_totals(v_invoice_id);
  end loop;

  return v_created;
end;
$$;

-- Directors trigger this through a server action; the cron job below calls it
-- for every tenant. revoke/grant keeps it callable only by authenticated users
-- (RLS still governs what the function's own queries can see).
revoke all on function public.generate_recurring_charges(uuid, date) from public;
grant execute on function public.generate_recurring_charges(uuid, date) to authenticated;
```

```sql
-- makes the view run under the caller's RLS, so the policy below is what

create view public.child_balance_status

  case

      select 1
      from public.charges ch
      join public.invoices i on i.id = ch.invoice_id

from public.children c;

grant select on public.child_balance_status to authenticated;
```

```ts
import type { SupabaseClient } from "@supabase/supabase-js";

import type { Database, InvoiceStatus } from "@/types/database.types";

export interface InvoiceListRow {
  id: string;
  guardianName: string;
  periodStart: string;
  periodEnd: string;
  dueDate: string;
  total: number;
  paid: number;
  status: InvoiceStatus;
}

function toRow(row: {
  id: string;
  period_start: string;
  period_end: string;
  due_date: string;
  total_amount: number;
  amount_paid: number;
  status: InvoiceStatus;
  guardians: { full_name: string }[] | { full_name: string } | null;
}): InvoiceListRow {
  const guardian = Array.isArray(row.guardians) ? row.guardians[0] : row.guardians;
  return {
    id: row.id,
    guardianName: guardian?.full_name ?? "Unknown",
    periodStart: row.period_start,
    periodEnd: row.period_end,
    dueDate: row.due_date,
    total: row.total_amount,
    paid: row.amount_paid,
    status: row.status,
  };
}

export async function getInvoiceList(
  supabase: SupabaseClient<Database>,
  tenantId: string,
): Promise<InvoiceListRow[]> {
  const { data } = await supabase
    .from("invoices")
    .select(
      "id, period_start, period_end, due_date, total_amount, amount_paid, status, guardians(full_name)",
    )
    .eq("tenant_id", tenantId)
    .order("period_start", { ascending: false });

  return (data ?? []).map(toRow);
}

export interface FamilyBalance {
  guardianName: string;
  invoices: InvoiceListRow[];
  outstanding: number;
}

export async function getFamilyBalance(
  supabase: SupabaseClient<Database>,
  tenantId: string,
  guardianId: string,
): Promise<FamilyBalance> {
  const [{ data: guardian }, { data: invoiceRows }] = await Promise.all([
    supabase.from("guardians").select("full_name").eq("id", guardianId).maybeSingle(),
    supabase
      .from("invoices")
      .select(
        "id, period_start, period_end, due_date, total_amount, amount_paid, status, guardians(full_name)",
      )
      .eq("tenant_id", tenantId)
      .eq("guardian_id", guardianId)
      .order("period_start", { ascending: false }),
  ]);

  const invoices = (invoiceRows ?? []).map(toRow);
  const outstanding = invoices
    .filter((i) => i.status === "open" || i.status === "partial")
    .reduce((sum, i) => sum + (i.total - i.paid), 0);

  return {
    guardianName: guardian?.full_name ?? "Unknown",
    invoices,
    outstanding: Math.round(outstanding * 100) / 100,
  };
}

export interface AgingRow {
  guardianId: string;
  guardianName: string;
  amount: number;
  daysOverdue: number;
}

export async function getRevenueSummary(
  supabase: SupabaseClient<Database>,
  tenantId: string,
): Promise<{
  billed: number;
  collected: number;
  outstanding: number;
  subsidyPending: number;
  aging: AgingRow[];
}> {
  const today = new Date().toISOString().slice(0, 10);

  const [{ data: invoiceRows }, { data: chargeRows }] = await Promise.all([
    supabase
      .from("invoices")
      .select("id, guardian_id, total_amount, amount_paid, status, due_date, guardians(full_name)")
      .eq("tenant_id", tenantId)
      .neq("status", "void"),
    supabase
      .from("charges")
      .select("subsidy_amount")
      .eq("tenant_id", tenantId)
      .eq("void", false),
  ]);

  const invoices = invoiceRows ?? [];
  const billed = invoices.reduce((sum, i) => sum + i.total_amount, 0);
  const collected = invoices.reduce((sum, i) => sum + i.amount_paid, 0);
  const subsidyPending = (chargeRows ?? []).reduce((sum, c) => sum + c.subsidy_amount, 0);

  const aging: AgingRow[] = invoices
    .filter((i) => (i.status === "open" || i.status === "partial") && i.due_date < today)
    .map((i) => {
      const guardian = Array.isArray(i.guardians) ? i.guardians[0] : i.guardians;
      const daysOverdue = Math.round(
        (new Date(today).getTime() - new Date(i.due_date).getTime()) / (24 * 60 * 60 * 1000),
      );
      return {
        guardianId: i.guardian_id,
        guardianName: guardian?.full_name ?? "Unknown",
        amount: Math.round((i.total_amount - i.amount_paid) * 100) / 100,
        daysOverdue,
      };
    })
    .sort((a, b) => b.daysOverdue - a.daysOverdue);

  return {
    billed: Math.round(billed * 100) / 100,
    collected: Math.round(collected * 100) / 100,
    outstanding: Math.round((billed - collected) * 100) / 100,
    subsidyPending: Math.round(subsidyPending * 100) / 100,
    aging,
  };
}

export async function getOutstandingTotal(
  supabase: SupabaseClient<Database>,
  tenantId: string,
): Promise<{ total: number; overdueCount: number }> {
  const today = new Date().toISOString().slice(0, 10);

  const { data } = await supabase
    .from("invoices")
    .select("total_amount, amount_paid, due_date")
    .eq("tenant_id", tenantId)
    .in("status", ["open", "partial"]);

  const rows = data ?? [];
  const total = rows.reduce((sum, i) => sum + (i.total_amount - i.amount_paid), 0);
  const overdueCount = rows.filter((i) => i.due_date < today).length;

  return { total: Math.round(total * 100) / 100, overdueCount };
}
```

```ts
"use server";

import { revalidatePath } from "next/cache";

import { requireRole } from "@/lib/auth/dal";
import { createClient } from "@/lib/supabase/server";
import type { ChargeType, PaymentMethod } from "@/types/database.types";

export type BillingActionState = { message?: string } | undefined;

function str(formData: FormData, key: string): string | null {
  const value = formData.get(key);
  if (typeof value !== "string") return null;
  const trimmed = value.trim();
  return trimmed === "" ? null : trimmed;
}

function num(formData: FormData, key: string): number | null {
  const raw = str(formData, key);
  if (raw === null) return null;
  const parsed = Number(raw);
  return Number.isFinite(parsed) ? parsed : null;
}

export async function recordPayment(
  _state: BillingActionState,
  formData: FormData,
): Promise<BillingActionState> {
  const session = await requireRole(["director", "platform_admin"]);

  const invoiceId = str(formData, "invoiceId");
  const amount = num(formData, "amount");
  const method = str(formData, "method") as PaymentMethod | null;
  const paidAt = str(formData, "paidAt");

  if (!invoiceId || amount === null || !method || !paidAt) {
    return { message: "Enter an amount, method, and payment date." };
  }
  if (amount <= 0) {
    return { message: "Payment amount must be greater than zero." };
  }

  const supabase = await createClient();

  const { data, error } = await supabase
    .from("payments")
    .insert({
      tenant_id: session.profile.tenantId,
      invoice_id: invoiceId,
      amount,
      method,
      paid_at: paidAt,
      recorded_by: session.profile.id,
      note: str(formData, "note"),
    })
    .select("id")
    .maybeSingle();

  if (error) return { message: "Couldn't record that payment. Try again." };
  if (!data) return { message: "You don't have access to this invoice." };

  await supabase.rpc("recalc_invoice_totals" as never, { p_invoice_id: invoiceId } as never);

  revalidatePath("/billing");
  revalidatePath(`/billing/${invoiceId}`);
  revalidatePath("/billing/revenue");
  revalidatePath("/dashboard");
}

export async function addManualCharge(
  _state: BillingActionState,
  formData: FormData,
): Promise<BillingActionState> {
  const session = await requireRole(["director", "platform_admin"]);

  const childId = str(formData, "childId");
  const type = str(formData, "type") as ChargeType | null;
  const description = str(formData, "description");
  const amount = num(formData, "amount");

  if (!childId || !type || !description || amount === null) {
    return { message: "Pick a child and type, and enter a description and amount." };
  }
  if (type === "tuition") {
    return { message: "Tuition charges are generated automatically — pick fee, credit, or adjustment." };
  }

  const supabase = await createClient();

  const { data: child } = await supabase
    .from("children")
    .select("id, location_id")
    .eq("id", childId)
    .eq("tenant_id", session.profile.tenantId)
    .maybeSingle();

  if (!child) return { message: "That child isn't in your center." };

  // Credits reduce what's owed, so they're stored negative regardless of how
  // the amount was typed in.
  const signed = type === "credit" ? -Math.abs(amount) : Math.abs(amount);

  const { data: payerRow } = await supabase
    .from("child_guardians")
    .select("guardian_id")
    .eq("child_id", childId)
    .eq("is_payer", true)
    .maybeSingle();

  if (!payerRow) return { message: "Set a paying guardian for this child first." };

  const today = new Date().toISOString().slice(0, 10);

  const { data: openInvoice } = await supabase
    .from("invoices")
    .select("id")
    .eq("tenant_id", session.profile.tenantId)
    .eq("guardian_id", payerRow.guardian_id)
    .in("status", ["open", "partial"])
    .lte("period_start", today)
    .gte("period_end", today)
    .maybeSingle();

  let invoiceId = openInvoice?.id ?? null;

  if (!invoiceId) {
    const { data: created, error: invoiceError } = await supabase
      .from("invoices")
      .insert({
        tenant_id: session.profile.tenantId,
        location_id: child.location_id,
        guardian_id: payerRow.guardian_id,
        period_start: today,
        period_end: today,
        due_date: today,
      })
      .select("id")
      .maybeSingle();

    if (invoiceError || !created) return { message: "Couldn't open an invoice for this family." };
    invoiceId = created.id;
  }

  const { error } = await supabase.from("charges").insert({
    tenant_id: session.profile.tenantId,
    location_id: child.location_id,
    child_id: childId,
    invoice_id: invoiceId,
    type,
    description,
    subsidy_amount: 0,
    parent_amount: signed,
    created_by: session.profile.id,
  });

  if (error) return { message: "Couldn't add that charge. Try again." };

  await supabase.rpc("recalc_invoice_totals" as never, { p_invoice_id: invoiceId } as never);

  revalidatePath("/billing");
  revalidatePath(`/billing/${invoiceId}`);
  revalidatePath("/billing/revenue");
}

export async function voidCharge(formData: FormData) {
  await requireRole(["director", "platform_admin"]);

  const chargeId = str(formData, "chargeId");
  const invoiceId = str(formData, "invoiceId");
  if (!chargeId || !invoiceId) return;

  const supabase = await createClient();

  await supabase
    .from("charges")
    .update({ void: true, voided_at: new Date().toISOString() })
    .eq("id", chargeId);

  await supabase.rpc("recalc_invoice_totals" as never, { p_invoice_id: invoiceId } as never);

  revalidatePath("/billing");
  revalidatePath(`/billing/${invoiceId}`);
  revalidatePath("/billing/revenue");
}

export async function generateNow(formData: FormData) {
  const session = await requireRole(["director", "platform_admin"]);

  // Defaults to today; the SQL function decides whether today actually starts
  // a period for each child's cadence, so an off-cycle click is a safe no-op.
  const on = str(formData, "on") ?? new Date().toISOString().slice(0, 10);

  const supabase = await createClient();
  await supabase.rpc("generate_recurring_charges", {
    p_tenant_id: session.profile.tenantId,
    p_on: on,
  });

  revalidatePath("/billing");
  revalidatePath("/billing/revenue");
  revalidatePath("/dashboard");
}
```

```tsx
import Link from "next/link";
import { notFound } from "next/navigation";

import { requireRole } from "@/lib/auth/dal";
import { createClient } from "@/lib/supabase/server";
import { getFamilyBalance } from "@/lib/billing/queries";
import { addManualCharge } from "@/lib/billing/actions";
import { INVOICE_STATUS_LABELS, TONE_CLASSES, invoiceStatusTone } from "@/lib/billing/labels";

export default async function FamilyBalancePage({
  params,
}: {
  params: Promise<{ guardianId: string }>;
}) {
  const { guardianId } = await params;
  const session = await requireRole(["director", "platform_admin"]);
  const supabase = await createClient();

  const { data: guardianRow } = await supabase
    .from("guardians")
    .select("id")
    .eq("id", guardianId)
    .eq("tenant_id", session.profile.tenantId)
    .maybeSingle();

  if (!guardianRow) {
    notFound();
  }

  const [balance, { data: childRows }] = await Promise.all([
    getFamilyBalance(supabase, session.profile.tenantId, guardianId),
    supabase
      .from("child_guardians")
      .select("is_payer, children(id, full_name)")
      .eq("guardian_id", guardianId),
  ]);

  const children = (childRows ?? [])
    .map((row) => {
      const child = Array.isArray(row.children) ? row.children[0] : row.children;
      return child ? { id: child.id, name: child.full_name } : null;
    })
    .filter((c): c is NonNullable<typeof c> => c !== null);

  return (
    <div className="max-w-[1000px]">
      <Link
        href="/billing"
        className="mb-3.5 inline-block text-[12.5px] font-semibold text-gray-500 hover:text-[var(--brand-primary)]"
      >
        &larr; Invoices
      </Link>

      <div className="mb-4 flex flex-wrap items-center gap-4 rounded-xl border border-gray-200 bg-white p-5">
        <div className="min-w-0 flex-1">
          <h1 className="font-serif text-xl font-semibold text-gray-900">{balance.guardianName}</h1>
          <p className="mt-1 text-[13px] text-gray-500">
            {children.map((c) => c.name).join(", ") || "No children linked"}
          </p>
        </div>
        <div className="text-right">
          <div className="text-2xl font-semibold text-gray-900 tabular-nums">
            ${balance.outstanding.toFixed(2)}
          </div>
          <div className="text-xs text-gray-500">outstanding</div>
        </div>
      </div>

      <section className="overflow-hidden rounded-xl border border-gray-200 bg-white">
        <div className="border-b border-gray-100 px-4.5 py-3.5">
          <h2 className="font-serif text-[14.5px] font-semibold text-gray-900">Invoice history</h2>
        </div>
        {balance.invoices.map((i) => (
          <Link
            key={i.id}
            href={`/billing/${i.id}`}
            className="flex items-center gap-3 border-b border-gray-100 px-4.5 py-3 hover:bg-gray-50"
          >
            <span className="flex-1 text-[13px] text-gray-500 tabular-nums">
              {i.periodStart} – {i.periodEnd}
            </span>
            <span className="text-[13px] text-gray-600 tabular-nums">${i.total.toFixed(2)}</span>
            <span
              className={`rounded-full px-2.5 py-1 text-[10.5px] font-bold tracking-[.07em] uppercase ${
                TONE_CLASSES[invoiceStatusTone(i.status, i.dueDate)]
              }`}
            >
              {INVOICE_STATUS_LABELS[i.status]}
            </span>
          </Link>
        ))}
        {balance.invoices.length === 0 && (
          <div className="px-4.5 py-6 text-center text-sm text-gray-500">No invoices yet.</div>
        )}

        <form
          action={addManualCharge.bind(null, undefined)}
          className="flex flex-col gap-2 border-t border-gray-100 px-4.5 py-4"
        >
          <div className="text-[12.5px] font-semibold text-gray-700">Add a one-off charge or credit</div>
          <div className="grid grid-cols-1 gap-2 sm:grid-cols-3">
            <select
              name="childId"
              required
              className="rounded-md border border-gray-300 px-3 py-2 text-sm focus:border-[var(--brand-accent)] focus:outline-none"
            >
              {children.length === 0 && <option value="">No children linked</option>}
              {children.map((c) => (
                <option key={c.id} value={c.id}>
                  {c.name}
                </option>
              ))}
            </select>
            <select
              name="type"
              className="rounded-md border border-gray-300 px-3 py-2 text-sm focus:border-[var(--brand-accent)] focus:outline-none"
            >
              <option value="fee">Fee</option>
              <option value="credit">Credit</option>
              <option value="adjustment">Adjustment</option>
            </select>
            <input
              type="number"
              step="0.01"
              min="0.01"
              name="amount"
              placeholder="Amount"
              required
              className="rounded-md border border-gray-300 px-3 py-2 text-sm focus:border-[var(--brand-accent)] focus:outline-none"
            />
          </div>
          <input
            name="description"
            placeholder="Description (e.g. Late pickup 8/19, Sibling discount)"
            required
            className="rounded-md border border-gray-300 px-3 py-2 text-sm focus:border-[var(--brand-accent)] focus:outline-none"
          />
          <button
            type="submit"
            disabled={children.length === 0}
            className="mt-1 self-start rounded-md border border-gray-300 px-4 py-2 text-sm font-medium text-gray-700 hover:bg-gray-50 disabled:cursor-not-allowed disabled:opacity-50"
          >
            Add charge
          </button>
        </form>
      </section>
    </div>
  );
}
```

**Known gaps, deliberately deferred:**
- **Overpayment → credit on next invoice.** The spec calls for excess payment to become a `credit` charge. `recalc_invoice_totals` clamps status to `paid` when `amount_paid >= total_amount` but does not auto-generate the credit row. A director can add the credit manually via the Task 9 form. Automating it belongs with the Stripe phase, when overpayment stops being a hand-entry edge case.
- **RLS/lifecycle tests.** The spec lists SQL-level RLS and lifecycle tests; this plan verifies both manually (Task 4 Step 3, Task 8 Step 4) rather than building DB test infrastructure in a repo that has none. Vitest covers only the pure date math.

**Type consistency:** `InvoiceListRow` is defined once in `queries.ts` and consumed by `invoice-table.tsx` and both list pages. `BillingActionState` is used uniformly by `recordPayment`/`addManualCharge`; `voidCharge`/`generateNow` take bare `FormData` (fire-and-forget), matching the existing split in `src/lib/incidents/actions.ts`. `periodFor`/`prorationFraction` signatures match between `periods.ts`, its test file, and the SQL that mirrors them.
